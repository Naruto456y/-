# Заметка для следующей сессии: парсер домашних заданий МЭШ

## Цель
Python 3.13 скрипт, который читает домашние задания из school.mos.ru и выводит
их таблицей по датам, плюс сохраняет в tasks.json. Параметр `--days N` (по умолчанию 7).
Поля: дата, предмет, время урока, текст задания, ссылки на вложения.

## Правила пользователя (обязательны)
- Логин, пароль и SMS-коды в скрипт не вводятся, не запрашиваются, не хранятся.
  Вход пользователь делает вручную в окне браузера, потом жмёт Enter в терминале.
- Скрипт только читает: ничего не отправляет, не отмечает выполненным, не меняет.
- Капчи и проверки не обходить: остановиться и сообщить пользователю.
- Токены и cookies только локально в папке `.session` (она в .gitignore).
- Токены не просить присылать в чат; в отчёты попадает только структура.

## Что сделано
- `explore_mesh.py`: скрипт-разведчик. Playwright Chromium, persistent context
  в `.session`, headless=False. Слушает JSON-ответы *.mos.ru на странице
  https://school.mos.ru/diary/homeworks/homeworks/ (адрес по памяти, не проверен).
  Пишет `discovery_report.json` (только пути, имена параметров, структура полей)
  и сырые ответы в `.session/raw/` (локально).
- `.gitignore`, `requirements.txt` (playwright).
- Реальных данных ещё не видели: из облачной сессии войти в МЭШ невозможно.

## Статус и следующий шаг
Пользователь переходит на локальную сессию. Копия explore_mesh.py лежит у него
в папке Python (может отличаться от версии в репозитории).
1. Пользователь запускает explore_mesh.py, входит вручную, открывает
   «Домашние задания» → «Ближайшие», жмёт Enter.
2. Присылает консольный вывод и discovery_report.json.
3. По отчёту писать `mesh_homework.py`: если есть JSON-запрос, делать его из
   контекста с cookies из `.session` (токен брать из cookies/заголовков
   в памяти, не печатать и не сохранять); иначе парсить HTML.
   Структуру ответа сначала описать пользователю, затем писать парсер.
